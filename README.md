

📊 Sales Dashboard – CSV Upload & Insights

A lightweight web-based sales analytics dashboard built with Flask, Pandas, and Matplotlib.
Upload a CSV file and instantly visualize key sales metrics including total revenue, category-wise sales, and daily sales trends.

🚀 Live Demo

🔗 Live App: https://your-app-name.onrender.com
🧩 Problem Statement
Small businesses often store sales data in CSV files but lack simple tools to analyze trends without technical expertise.
This project solves that by offering an easy-to-use dashboard that converts raw sales data into meaningful insights.

✅ Features

Upload sales data via CSV file

Automatically calculates:

Total sales

Category-wise sales

Displays:

Clean tabular summaries

Colorful bar chart for daily sales trends

Responsive and modern UI (HTML + CSS)

Deployed as a live web application

🛠 Tech Stack

Backend: Flask (Python)

Data Processing: Pandas

Visualization: Matplotlib, Seaborn

Frontend: HTML, CSS (no Streamlit)

Deployment: Render.com
